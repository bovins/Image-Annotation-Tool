# 🖍️ Image Annotation Tool · 离线图像标注工具

基于本地 Fabric.js 5.5.2 的纯前端工具，适用于机械结构图、液压原理图、试验照片和技术报告配图。
完整解压后双击 **index.html** 即可使用，不需要服务器、Node.js、安装依赖或联网。图片和工程留在本机。

[查看明亮主题](docs/editor-light.png) · [查看导出预览](docs/export-preview.png)

## 快速使用

1. 上传、拖入或粘贴图片；文件选择和拖入支持批量导入，标签名默认来自文件名。
2. 选择文字、箭头、矩形、尺寸等工具标注；选中后可改样式、拖动控制点、旋转和缩放。
3. 测量前点击「两点比例标定」，点击已知长度的两端，输入距离和单位。
4. **保存工程**保存当前图片；顶栏**工作区 → 保存工作区**保存全部标签页。导出图片不会清除未保存标记。
5. PNG/JPG 导出前检查预览，也可批量逐图导出。请另存工程文件，浏览器草稿不作为唯一备份。

## 工具与工作流

| 类别 | 功能 |
| --- | --- |
| 基础 | 文字、矩形、消息框、直线、曲线、手写、箭头、曲线箭头、步骤序号 |
| 测量 | 尺寸、三点角度、多边形面积，每张图独立比例标定 |
| 引出 | 文字引出、引出区域、图引出、多引出，保留控制点编辑 |
| 其他 | 圆形/方形放大镜、表情/图片贴图、马赛克 |
| 效率 | 连续标注、Shift 约束、屏幕容差吸附、六种对齐、右键菜单、复制/粘贴样式 |
| 样式 | 机械尺寸/问题反馈/论文插图预设，用户预设创建、更新、删除及离线 JSON 迁移 |
| 图层 | 选择定位、重命名、排序、多选、批量显隐/锁定/删除、逻辑分组 |
| 工程 | 独立未保存标记、关闭提醒、撤销回保存状态、IndexedDB 草稿、文件校验和工作区 |
| 导出 | 原图/全部可见标注/自定义矩形、倍率、透明/白色/自选底色、JPG 质量、统一预览和输出 |
| 界面 | 石墨灰/明亮主题、本地线性图标、分组顶栏、紧凑工具区、面板折叠、浮动缩放与选中快捷条 |

新图片超过最大边 4096 会实际重采样并提示原始/工作尺寸；底图、图引出、马赛克、保存和导出共用工作图坐标，保留透明度。
测量反映画布中的变换后几何；普通照片的透视和镜头畸变可能影响精度，不提供透视校正。

## 保存与兼容

- 单图工程：`app: image-annotator`，当前版本 2；可读旧版 1。
- 工作区：`app: image-annotator-workspace`，版本 1；载入时追加标签页，保留当前内容。
- 用户预设：`app: image-annotator-presets`，版本 1；只保存样式。
- 草稿：IndexedDB 中的本浏览器恢复副本；启动时选择恢复或丢弃，失败时仍可手动保存。
- 支持时显示另存为；不支持时降级浏览器下载。取消正常退出，写入失败明确提示。
- 下载方式只能确认已交给浏览器，无法确认最终写盘，请检查下载结果。

兼容目标保持 **Chrome 109、Edge 109、Firefox 115 ESR**。本次实测为 Windows 当前 Edge 的 `file://`，并阻断 HTTP/HTTPS，不能等同于三个旧版本通过。
真实系统 125% 缩放、旧版浏览器和 Win7 仍需手工验证，详见[验证记录](docs/修复与验证.md)。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+S / Ctrl+E | 保存工程 / 导出预览 |
| Ctrl+D / Delete | 复制 / 删除 |
| Ctrl+Shift+C / Ctrl+Shift+V | 复制 / 粘贴兼容样式 |
| 方向键 / Shift+方向键 | 微调 1 / 10 工作图像素 |
| V / Esc | 选择工具 / 取消当前操作 |
| 空格拖动 / 中键拖动 | 平移画布 |
| Shift 绘制 | 45° 倍角直线、箭头、尺寸；等比例矩形、消息框 |
| Enter / 右键 | 完成面积、多引出 |

文字输入和中文输入法组合期间不拦截标注快捷键。详见[使用说明](使用说明.md)。

## 开发与测试

普通用户不需要执行本节。原有四项 Node 模拟测试无需安装依赖：

```sh
node test-verify.js
node test-render.js
node test-tools.js
node test-app-smoke.js
```

真实浏览器回归需要 Node 18+、开发依赖和本机 Edge：

```sh
npm ci
npm test
npm run test:browser
node tests/baseline.js  # 隔离回放原提交的历史/放大镜/复制缺陷
```

Playwright 仅为开发依赖（Apache-2.0），没有新增运行时依赖。截图写入忽略的 `test-results/`。DOM 模拟和真实浏览器分别报告，不给模拟 Image 添加 Canvas 能力。
