# 🖍️ Image Annotation Tool（图像标注工具）

一个**纯前端、可直接离线运行**的图像标注网页。打开 `index.html` 即可使用，无需安装、无需服务器；
fabric.js 5.5.2 已内置在 `vendor/`，浏览器直接加载本地文件也能运行。

## 功能一览

| 分类 | 工具 |
| --- | --- |
| 基础类 | 文字、矩形（白色描边）、消息框、直线、曲线（样条，锚点可拖动）、手写、箭头、曲线箭头、步骤序号 |
| 尺规类 | 尺寸（长度测量）、角度（三点测角）、面积（多边形面积） |
| 引出类 | 文字引出、引出区域、图引出、多引出 |
| 视图类 | 圆形放大镜、方形放大镜、贴图（48 种表情 + 自定义）、马赛克 |

- **无限画布**：滚轮缩放、空格/中键平移，图片之外也可标注
- **图层系统**：每个标注自动建层，支持排序、显隐、锁定；图层操作全部可撤销
- **全局样式记忆**：线条/文字/图形/阴影等默认样式自动保存，下次打开自动恢复
- **导出**：PNG（图片外透明）/ JPG（质量可调）/ 一键复制 PNG 到剪贴板；导出选项面板（分辨率、是否包含图片外标注）
- **多图标签页**：可同时打开多张图片，每张的标注、图层、历史、马赛克各自独立
- **撤销/重做**：快照已做瘦身（马赛克 dataURL 去重），历史条目不随马赛克增长而膨胀
- **主题切换**：暗色/亮色，平滑过渡；界面动效适配「减少动态效果」系统设置
- **Windows 7 兼容**：Chrome 109+ / Firefox 115 ESR+ / Edge 109+

详细使用说明见 [使用说明.md](使用说明.md)。

## 文件结构

```
index.html            页面入口
css/style.css         界面样式
js/objects.js         自定义标注对象
js/tools.js           工具手势交互与马赛克图层
js/app.js             面板、历史记录、导出、工程存取、快捷键、多图标签页
vendor/fabric.min.js  Fabric.js 5.5.2（本地依赖，离线可用）
使用说明.md           完整使用文档
```

## 运行测试（Node）

```bash
node test-verify.js       # 对象库 API 验证
node test-render.js       # 渲染与序列化集成测试
node test-tools.js        # 工具交互集成测试
node test-app-smoke.js    # app.js 冒烟测试（多图标签页/历史/导出选项）
```
