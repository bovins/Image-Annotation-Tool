# 图像标注工具

在浏览器里给图片添加标注、测量尺寸，并导出 PNG 或 JPG。可同时编辑多张图片，保存工程后继续修改。

## 开始使用

1. 下载仓库 ZIP 并完整解压，双击 `index.html`。也可以从仓库页面的站点入口打开在线版。
2. 上传图片，或将图片拖入画布。支持用 `Ctrl+V` 粘贴剪贴板里的图片。
3. 从左侧选择工具。右栏「全局属性」设置新标注的默认样式，「单个样式」用于调整已选中的标注。
4. 用 `Ctrl+S` 保存工程，或用 `Ctrl+E` 打开导出预览。

## 功能

| 功能 | 支持的操作 |
| --- | --- |
| 标注 | 添加文字、矩形、直线、曲线、手写、步骤序号及引出线。箭头支持四种样式。 |
| 测量 | 测量长度、角度和多边形面积。选择两个已知距离的点可设置比例和单位。短尺寸线会自动缩小两端箭头，尖端仍对准原端点。 |
| 编辑 | 使用图层、锁定、显隐、吸附和对齐整理标注。点击可见部分选中，`Alt` + 单击可在重叠标注间轮换。 |
| 放大与遮盖 | 使用圆形或方形放大镜检查细节，添加贴图或用马赛克遮盖区域。 |
| 导出 | 预览导出范围、倍率、背景和格式。支持透明 PNG、JPG 和批量导出。 |

## 保存与恢复

- 「保存工程」保存当前图片及标注。「保存工作区」保存全部图片标签，便于重新载入。
- 图片和标注在浏览器内处理。自动草稿保存在当前浏览器，可用来恢复编辑进度。需要长期保留时，请保存工程文件。
- 导出 PNG 或 JPG 后，可将图片直接用于其他文档。需要继续编辑标注时，载入保存的工程文件。

## 运行方式

本地版只需浏览器。请保留解压后的 `index.html`、`css/`、`js/` 和 `vendor/`。页面底部的构建编号可用于核对当前打开的版本。
